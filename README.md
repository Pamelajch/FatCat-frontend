## Project Setup

# 先下載node.js
https://nodejs.org/zh-tw/download
# 在cmd中測試是否下載成功(查看版本)
輸入
```sh
npm -v
```
若有版本跑出來就代表有下載成功
安裝相關套件
```sh
npm install
```

### 執行程式

```sh
npm run dev
```
### 點擊跑出來的local連結
看到畫面代表執行成功
